01
치명
첫 화면이 막다른 골목입니다
접속하면 YouTube 업로드 탭이 열리는데, 서버 영상이 0개면 할 수 있는 일이 없습니다. 빈 상태 문구도 "업로드할 서버 영상이 없어요"에서 끝나고, 어디서 영상을 만들어 오는지 알려주지 않습니다. 정작 이 앱의 시작점은 다운로드나 라이브 녹화입니다. 처음 온 사람이 첫 화면에서 길을 잃습니다.
고치는 법
기본 탭 → 다운로드
빈 상태에 이동 버튼
02
치명
일한 기록이 화면에 남지 않습니다
다운로드 탭은 주소창 하나가 전부고 화면의 82%가 빈 배경입니다. 방금 받은 파일도, 어제 받은 파일도 보이지 않습니다. 라이브 녹화 탭도 73%가 비어 있고 지난 녹화 이력이 없습니다. 결과를 확인하려면 결국 탐색기를 여는 수밖에 없습니다. 웹 UI를 만든 이유가 절반 사라집니다.
고치는 법
최근 결과 목록 추가

03
마찰
같은 채널을 두 탭에서 관리합니다
"라이브 녹화"와 "채널 관리"가 둘 다 채널 목록 + 채널 추가 버튼입니다. 한쪽은 일시중지, 다른 쪽은 비활성화인데 이름이 다르니 같은 동작인지도 알 수 없습니다. 탭을 왕복하며 "어느 쪽에서 지웠더라"를 외워야 합니다.

04
마찰
되돌릴 수 없는 버튼이 제일 약하게 그려집니다
채널 삭제는 배경도 테두리도 투명하고 색은 회색 #655b70입니다. 바로 옆 비활성화(되돌릴 수 있음)는 흰 배경에 테두리까지 있습니다. 위험한 쪽이 안전한 쪽보다 눈에 덜 띕니다. 확인 절차도 없습니다.

05
다듬기
한글에 모노 폰트를 씌운 곳이 15군데입니다
IBM Plex Mono에는 한글 글리프가 없어 Pretendard로 폴백되는데, 모노 폭 규칙이 남아 글자 사이가 벌어집니다. "영상을 먼저 골라 주세요", "왼쪽 목록에서 영상 하나를 골라 주세요" 같은 안내문이 여기 해당합니다. 경로·용량·시각처럼 자릿수를 맞춰야 하는 값에만 모노를 남기면 됩니다.

다듬기
